# 🌿 ハビトラ (Habitra)

A clean, modern habit tracker web application built with React + TypeScript + Vite.

## Features

- **習慣の追加** – Add new habits with a custom name and emoji/icon
- **習慣の一覧表示** – View all your habits at a glance
- **毎日のチェック** – Mark habits as complete for today
- **連続記録** – Track your current streak (🔥 N日連続) for each habit
- **習慣の削除** – Remove habits you no longer need
- **データ永続化** – All data is saved to localStorage (no backend required)

## Tech Stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) for fast builds
- [Tailwind CSS v3](https://tailwindcss.com/) for styling

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build

```bash
npm run build
```
